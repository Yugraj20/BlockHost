Everything Under One Hood

Engineered for maximum reliability, speed, and zero configuration headaches.

Zero Port-Forwarding

In-process implementation of the official playit-agent protocol v2. Automatically obtains a public domain with zero external binaries or router adjustments.

Automated Adoptium Java

Never install Java manually again. ChunkHarbor detects the required version for your Minecraft release and downloads Eclipse Temurin JDK 8, 17, 21, or 25 on demand.

Real-Time Sparklines

Live telemetry graphs showing exact CPU usage, JVM memory allocations, disk activity, and 20.0 TPS stability history.

Mojang Player Manager

Instant Mojang UUID and skin resolution. Easily toggle Whitelisting, grant OP levels 1–4, and ban players or malicious IPs with automatic reason logging.

In-App Code Editor

Syntax-highlighted editor for server.properties, paper-global.yml, and JSON files. Generates automatic .bak safety copies before every save.

Chunk-Safe Backups & Cron

Automated backups execute live save-off and save-all flush commands before compressing to guarantee 100% corruption-free world archives.
